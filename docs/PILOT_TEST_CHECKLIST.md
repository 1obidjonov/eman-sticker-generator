# Пилотное тестирование Eman Sticker Generator 0.8 RC

Этот чек-лист используется для решения «готово / не готово» перед передачей
приложения первой рабочей группе. Проверка проводится на чистом профиле
Windows 10 или Windows 11 x64.

## 1. Установка и жизненный цикл

- [ ] Установщик запускается и показывает имя Eman Sticker Generator.
- [ ] Можно выбрать каталог установки.
- [ ] Создаются ярлыки рабочего стола и меню «Пуск».
- [ ] После установки открывается одно окно приложения.
- [ ] Повторный запуск фокусирует существующее окно, а не создаёт второе.
- [ ] После перезапуска сохраняются тема, параметры экспорта и шаблоны.
- [ ] Обновление с 0.7.0 на 0.8.0-rc.__ не повреждает пользовательские данные.
- [ ] Удаление приложения не удаляет шаблоны и настройки.
- [ ] После удаления ярлыки и файлы программы отсутствуют.

Для публичного распространения установщик должен иметь действительную
цифровую подпись. Неподписанная сборка допустима только для внутреннего пилота
с заранее согласованным предупреждением Windows SmartScreen.

Перед ручной проверкой убедитесь, что `windows-lifecycle-report.json` имеет
статус `passed`: он автоматически проверяет тихую установку, два запуска,
удаление приложения и сохранность пользовательских данных.

## 2. Основной рабочий сценарий

- [ ] Создать шаблон с SVG-фоном.
- [ ] Создать шаблон с PNG- или JPG-фоном.
- [ ] Добавить текстовые поля: название, цена, старая цена, артикул.
- [ ] Добавить QR-поле и проверить считывание телефоном.
- [ ] Переместить и изменить размер полей; сохранить шаблон.
- [ ] Закрыть и открыть шаблон — координаты и оформление не изменились.
- [ ] Проверить перенос длинного названия, уменьшение шрифта и многоточие.
- [ ] Экспортировать одну наклейку в SVG, PNG и JPG.
- [ ] Открыть итоговый ZIP и проверить все выбранные форматы.

Критерий: превью и экспорт не имеют заметных расхождений в переносе текста,
положении полей и QR-коде.

перезапуска приложения.

## 4. Ошибки и безопасность

- [ ] Пустой и некорректный URL отклоняется до запуска задачи.
- [ ] `file:`, URL с логином/паролем и локальные адреса отклоняются.
- [ ] Недоступная страница, 403, тайм-аут и страница без товара дают понятную
  ошибку отдельной карточки.
- [ ] Внешние ссылки не открываются внутри окна приложения.
- [ ] Перетаскивание веб-страницы в окно не заменяет интерфейс.
- [ ] При повреждённом `settings.json` запускаются безопасные настройки.
- [ ] Несохранённые изменения редактора защищены предупреждением.

## 5. Темы, масштаб и доступность

- [ ] Светлая, тёмная и системная темы отображаются без нечитаемого текста.
- [ ] Системная тема реагирует на смену темы Windows.
- [ ] Режим уменьшенной анимации отключает декоративные переходы.
- [ ] Интерфейс остаётся рабочим при масштабе Windows 100%, 125% и 150%.
- [ ] Минимальный размер окна не скрывает основные действия.

## 6. Диагностика и обращение в поддержку

- [ ] «Проверить» показывает версию приложения, Electron/Chromium и результат
  запуска браузера.
- [ ] «Технические журналы» открывает локальную папку журналов.
- [ ] «Отчёт для поддержки» создаёт ZIP, который открывается без ошибок.
- [ ] В отчёте есть `diagnostics.json`, `settings.json`, `README.txt` и журналы.
- [ ] В отчёте нет шаблонов, URL товаров, готовых наклеек и пользовательских
  путей профиля.
- [ ] Кнопка результата показывает созданный ZIP в проводнике.

## 7. Решение о выпуске

| Уровень | Критерий |
|---|---|
| Блокер | Потеря данных, невозможность установки/запуска, повреждённый экспорт |
| Критичный | Системный сбой генерации, утечка приватных данных, неработающий парсер на всех пилотных сайтах |
| Допустимый | Локальный визуальный дефект с понятным обходным путём |

Пилот разрешён, если нет открытых блокеров и критичных дефектов, выполнена
полная автоматическая проверка `npm run check`, зафиксирован SHA-256
установщика и назначен ответственный за сбор обратной связи.
