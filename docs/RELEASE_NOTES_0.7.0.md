# Eman Sticker Generator 0.7.0

Версия 0.7.0 автоматизирует проверку и выпуск Windows-сборок.

## Новое

- quality workflow для каждого изменения и pull request;
- Windows x64 release workflow по Git-тегу или ручному запуску;
- скрытый runtime smoke-режим упакованного приложения;
- проверка загрузки renderer и доступности безопасного preload API;
- CycloneDX SBOM production-зависимостей;
- `release-manifest.json` с размером, ролью и SHA-256 каждого файла;
- внешний `checksums.sha256`;
- проверка обязательного имени, размера и PE-заголовка установщика;
- контроль соответствия Git-тега версии приложения;
- опциональная Authenticode-подпись через секреты CI;
- автоматическая публикация проверенного GitHub Release.

## Сохранённые возможности 0.6

Шаблоны, пакетная генерация, экспорт, production-защита, ротационные журналы и
обезличенный отчёт поддержки работают без изменения формата пользовательских
данных.

## Ограничения

Неподписанный установщик предназначен только для внутреннего пилота. Публичный
релиз должен пройти Windows workflow с настроенным сертификатом и получить
Authenticode-статус `Valid`.
