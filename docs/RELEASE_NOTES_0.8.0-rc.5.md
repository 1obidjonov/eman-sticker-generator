# Eman Sticker Generator 0.8.0-rc.5

Пятый Windows Release Candidate устраняет ложные таймауты тестов на холодном
Windows runner, обнаруженные при проверке `0.8.0-rc.4`.

## Исправлено

- тестам Sharp-экспорта выделено до 30 секунд вместо стандартных 5 секунд;
- холодному запуску Chrome/Edge в browser hooks выделено до 90 секунд;
- тестовые файлы по-прежнему выполняются последовательно одним worker, поэтому
  увеличение лимитов не скрывает конкуренцию за ресурсы;
- production/runtime-таймауты приложения и packaged smoke gate не изменены.

## Сохранённые проверки

- production-аудит и 62 автоматических теста;
- одиночный и пакетный demo-экспорт;
- проверка содержимого `app.asar` и раннего Electron bootstrap;
- NSIS-сборка Windows x64;
- smoke-тест распакованного и установленного приложения;
- тихая установка, два запуска, сохранность данных и удаление;
- CycloneDX SBOM, release-манифест и SHA-256.

## Статус

Это кандидат для внутреннего пилота. Публичная публикация разрешена только
после успешного Windows workflow и действительной Authenticode-подписи.
