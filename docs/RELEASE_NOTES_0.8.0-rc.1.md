# Eman Sticker Generator 0.8.0-rc.1

Первый Windows Release Candidate добавляет автоматическую проверку установки,
повторного запуска и удаления приложения.

## Новое

- RC-версия и отдельный prerelease-контур;
- проверка, что тег указывает именно на собираемый commit;
- тихая установка NSIS в изолированный каталог Windows runner;
- проверка ярлыков рабочего стола и меню «Пуск»;
- два запуска установленного приложения через runtime smoke;
- контроль сохранности `settings.json` после перезапуска;
- тихое удаление с проверкой удаления программы и ярлыков;
- подтверждение, что пользовательские данные не удалены;
- `windows-lifecycle-report.json` в составе release-манифеста;
- запрет публикации сборки без действительной Authenticode-подписи;
- tag push создаёт только внутренний artifact, исключая случайный публичный
  выпуск неподписанного кандидата.

## Сохранённые возможности

Редактор шаблонов, пакетная генерация, экспорт SVG/PNG/JPG, QR-коды,
production-защита, журналы, отчёт поддержки, SBOM и SHA-256 работают без
изменения формата пользовательских данных.

## Статус

Это кандидат для внутреннего пилота, а не финальная версия 1.0. Переход к
публичному prerelease разрешён только после успешного Windows workflow и
Authenticode-статуса `Valid`.
