# Eman Sticker Generator 0.8.0-rc.4

Четвёртый Windows Release Candidate устраняет неоднозначность запуска
runtime smoke-теста, обнаруженную в диагностическом прогоне `0.8.0-rc.3`.

## Исправлено

- smoke-режим активируется как аргументами командной строки, так и изолированными
  переменными окружения Windows runner;
- ранний Electron bootstrap фиксирует запуск до загрузки основного процесса и
  формирует аварийный smoke-отчёт при ошибке импорта;
- перед запуском приложение проверяется внутри `app.asar`: main entry, preload,
  основной процесс и renderer должны присутствовать;
- Windows diagnostics сохраняют bootstrap, Electron, stdout/stderr и application
  logs;
- для headless Windows runner отключено аппаратное GPU-ускорение.

## Сохранённые проверки

- production-аудит и полный набор автоматических тестов;
- одиночный и пакетный demo-экспорт;
- NSIS-сборка Windows x64;
- запуск распакованного приложения;
- тихая установка, два запуска, сохранность данных и удаление;
- CycloneDX SBOM, release-манифест и SHA-256.

## Статус

Это кандидат для внутреннего пилота. Публичная публикация разрешена только
после успешного Windows workflow и действительной Authenticode-подписи.
