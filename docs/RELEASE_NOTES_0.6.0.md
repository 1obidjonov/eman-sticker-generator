# Eman Sticker Generator 0.6.0

Версия 0.6.0 переводит завершённый MVP в состояние внутреннего пилота.

## Новое

- конфигурация Windows x64 NSIS-установщика и portable-сборки;
- бренд Eman Sticker Generator и иконка приложения;
- запуск только одного экземпляра приложения;
- усиленная изоляция production-окна и Content Security Policy;
- структурированные ротационные журналы;
- запись критических ошибок main, renderer и дочерних процессов;
- встроенная выгрузка обезличенного ZIP-отчёта для поддержки;
- автоматическая release-проверка файлов, ресурсов и production-зависимостей;
- обновлённые Archiver 8 и Sharp 0.35 без известных npm audit уязвимостей;
- инструкция сборки и чек-лист пилотного тестирования.

## Сохранность данных

Установщик работает в профиле пользователя. Удаление приложения не удаляет
шаблоны, настройки и журналы. Отчёт поддержки не включает шаблоны, ссылки на
товары, созданные наклейки и экспортированные файлы.

## Ограничение пилота

Windows-сборке нужен установленный Chrome, Microsoft Edge или вручную
выбранный Chromium. Публичная раздача требует подписанного установщика;
неподписанная сборка предназначена только для внутреннего пилота.
