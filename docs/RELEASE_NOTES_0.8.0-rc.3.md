# Eman Sticker Generator 0.8.0-rc.3

Третий Windows Release Candidate исправляет завершение runtime smoke-теста,
обнаруженное после успешной NSIS-сборки версии `0.8.0-rc.2`.

## Исправлено

- smoke-режим завершает Electron через предсказуемый `app.exit`;
- внешний Windows gate ограничивает smoke-процесс 60 секундами;
- зависший процесс завершается вместе с дочерними процессами;
- новый release-запрос отменяет незавершённый Windows RC перед запуском
  следующего кандидата.

## Сохранённые проверки

- production-аудит и полный набор из 60 тестов;
- одиночный и пакетный demo-экспорт;
- NSIS-сборка Windows x64;
- запуск распакованного приложения;
- тихая установка, два запуска, сохранность данных и удаление;
- CycloneDX SBOM, release-манифест и SHA-256.

## Статус

Это кандидат для внутреннего пилота. Публичная публикация разрешена только
после успешного Windows workflow и действительной Authenticode-подписи.
