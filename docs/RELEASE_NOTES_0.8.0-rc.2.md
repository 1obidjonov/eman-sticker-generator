# Eman Sticker Generator 0.8.0-rc.2

Второй Windows Release Candidate исправляет кроссплатформенный запуск
контрольных экспортов, обнаруженный Windows gate версии `0.8.0-rc.1`.

## Исправлено

- demo-экспорт теперь использует общий механизм выбора Chrome/Edge;
- пакетный demo-проход больше не пытается запускать Linux Chromium на Windows;
- интеграционные тесты, приложение и контрольные сценарии используют один
  `BrowserFactory`;
- автоматизирован запрос RC-тега после зелёного workflow `Quality`.

## Проверки кандидата

- production-аудит и полный набор из 60 тестов;
- генерация одиночного и пакетного demo-экспорта;
- NSIS-сборка Windows x64;
- smoke-тест распакованного приложения;
- тихая установка, два запуска, проверка сохранности данных и удаление;
- CycloneDX SBOM, release-манифест и SHA-256.

## Статус

Это кандидат для внутреннего пилота. Публичная публикация разрешена только
после успешного Windows workflow и действительной Authenticode-подписи.
